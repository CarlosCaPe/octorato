# /choice: From an Idea to a Decision

The operator hands over an idea, often half-formed ("something like this"). `/choice` does not list options and hand the choosing back. It does the choosing, with sources, and says what would change its mind.

Usage: `/choice <the idea>`. With no argument, apply it to the last idea the operator stated in the conversation.

## Workflow

Run the five steps in order. Each step is a short section of the answer, not an essay.

1. **Develop.** Restate the idea in one or two sentences, using the operator's own words for anything he classified himself. Fill the gaps the idea leaves open (name, audience, price, format, scope) with concrete proposals, and mark each filled gap as yours.
2. **Debate.** Give the strongest case for and the strongest case against. Each argument carries its evidence: a measured number, a file, a rule, a source read in this session. An argument with no evidence is labelled as an assumption. Seek before asserting: `query_connectome.py memory "<idea>"` for what the brain already decided, and a real lookup (search, browser, query) for any market or factual claim the debate rests on.
3. **Weigh.** Say which arguments decide the matter and which are noise. Name the one or two facts that carry the most weight, and what remains unmeasured.
4. **Defend.** Pick the winning version and defend it against the best objection left standing. If the winner is a modified version of the idea, say exactly what changed and why.
5. **Decide.** One line: **GO**, **GO WITH CHANGES** (list them), or **NO-GO**. Then the single next step, and the observation that would reverse the decision.

## Rules

- Decide. Never end on "it depends" or a menu. If a decision is truly the operator's (money, consent, an irreversible act), decide everything else and state that one question last.
- A prior decision of the operator found in memory is an input, not a wall: if the idea contradicts it, show the contradiction with its source and decide anyway.
- Opinion is allowed here because the operator asked for one; it stays sourced. No unsourced gut-calls.
- Keep it short: the five sections fit on one screen for a simple idea.
- Writes still follow the 4D Gate. `/choice` decides; it does not start building unless the operator says so.
