# v11 reply panel

Spec: `docs/specs/202610141340-v11-reply-panel/` (FR-01 to FR-05, AC-01 to AC-17). This page is the source the registry row `FLOW.panel-before-reply` points at from its CLAUDE.md anchor "Reply panel".

v7 made an unverified send to a third party impossible: no message leaves without a PASS panel receipt for its exact digest (`FLOW.panel-before-send`). v11 moves that floor to the operator. Every reply the main loop gives him carries a PASS panel receipt for its exact text, recorded by a hook from an independent reviewer, or the turn is sent back.

## Why Stop, and not before display

Claude Code has no hook that can stop text before it is displayed: "MessageDisplay hooks have no decision control. They can't block the message" (code.claude.com/docs/en/hooks). MessageDisplay can replace a streamed delta on screen, but it runs per streamed batch, before the whole reply and its digest exist. So the gate runs at Stop, after the reply was shown. The protocol keeps an unreviewed reply off the screen: draft the reply, have a reviewer read it, then emit exactly the reviewed text. The gate makes skipping the protocol cost a rewrite turn, every time.

## The protocol

1. Write the reply to a file and run `python3 ~/.claude/scripts/panel_digest.py --panel-request --to operator --body-file <file>`. It first runs the preflight (`scripts/panel_preflight.py`): every other Stop hook that judges reply text runs on the draft, appended to a copy of the session transcript, and when one would block, no block is printed and the command exits 1, so the text the reviewers read is the text that ends the turn. It then prints the source class and quorum on stderr and the reviewer block (`PANEL-TO: operator`, `PANEL-BODY-BEGIN` ... `PANEL-BODY-END`, `PANEL-SHA256`) on stdout. `--preflight` runs only the check; `--no-preflight` skips it.
2. Launch reviewer subagents with that block: three for a SELF reply, one for a SOURCED reply (see the quorum below). Its agent type must match `receipt_ledger.PANEL_AGENT_TYPE` (`qa|review|reality|evidence|checker|verif|audit|panel`: Reality Checker, Code Reviewer, Evidence Collector). general-purpose, claude and fork do not match. The reviewer repeats the block and ends with `PANEL-VERDICT: PASS | NEEDS-WORK` and `PANEL-SHA256`.
3. `r__subagent-stop__qa-receipt.py` records a `panel` receipt only when the reviewer's own report carries the block and it recomputes to the stated digest. No new receipt machinery: a recipient is free text in `PANEL-TO`.
4. Emit exactly the reviewed text as the final reply.

Reviewers run in the background in this harness, so the main loop can end a turn while it waits. That waiting stop is a status line of at most 30 words with no claim in it, and the gate lets it through while any subagent of the session still runs.

## The gate

`scripts/g__stop__reply-panel.py`, on Stop, timeout 20 seconds. It reads the Stop payload (`last_assistant_message`, `stop_hook_active`, `transcript_path`, `session_id`). The digest is `panel_digest.digest(last_assistant_message, recipients=["operator"])`: whitespace layout does not change it, one changed word does.

It exits 0 when the first of these holds, in this order:

| # | Condition |
|---|---|
| 1 | `OCTO_REPLY_PANEL=off` in the hook's own environment. Read before any import that can fail. |
| 2 | `last_assistant_message` is an empty or whitespace string. An absent key is not empty: the gate cannot decide and exits 2 ("payload has no last_assistant_message"). |
| 3 | The operator's own prompt for the turn carries the word `panel-skip`. |
| 4 | The reply is a status line (at most 30 whitespace-split words, no claim marker) and a subagent of this session is still running. |
| 5 | The deciding receipt for the digest in this session (`receipt_ledger.panel_receipts_for`, first entry) is a PASS with `verdict_ts` strictly newer than the operator's prompt, and PASS receipts newer than the prompt come from at least the quorum of distinct reviewer agent ids: 3 for a SELF reply, 1 for a SOURCED reply. |

Otherwise it exits 2. Its stderr names the digest, the panel-request command and the accepted reviewer types, and never the skip word, so its own feedback cannot read as a waiver. `stop_hook_active` changes nothing: there is no block-once.

**The operator's prompt.** The gate walks the transcript backwards with the send gate's `_prompt_entries_reversed`, `_origin`, `_is_operator_opener` and `_entry_text`, loaded by file name. It passes over tool results, task notifications, peer messages and hand-backs, sidechain entries and every `isMeta` entry (Stop-hook feedback lands as a user entry with `isMeta: true`). The first entry whose `origin.kind` is `human`, or that has no origin, is the prompt; if that entry is not harness-written (`_is_operator_opener` fails), there is no prompt and the gate exits 2. An entry with any other origin kind also ends the walk with no prompt, as the send gate's `turn_read` does. A compact summary (`isCompactSummary: true`) reached before any human entry means a context continuation opened the turn (AC-22): it carries no operator words, so the anchor is the summary itself, with empty text and its own timestamp as the newer-than bound. A receipt must then be newer than the summary. A summary the harness did not write (no uuid or timestamp) ends the walk with no prompt. A helper missing from the send gate is an error that names it.

**The quorum scales with the source (FR-06).** Operator directive 2026-10-14: a reply whose basis is SELF is treated as a likely hallucination and needs a panel of three. Every line of the reply that starts with `Provenance:`, `Procedencia:` or `Herkunft:` is a provenance line (leading blanks, a `>` and markdown emphasis around the label are tolerated). The reply is SELF when it has none, or when ANY of them has no `Basis` field, an empty Basis, a Basis that is only (ignoring case, surrounding blanks and trailing punctuation) `none`, `nothing`, `n/a`, `na` or a run of hyphens, en dashes or em dashes, or a Basis that names self as its source. The field is the word `Basis` in any case followed by a colon or by whitespace (`Basis: /path` and `Basis /path` are the same field), and the label may be followed by a colon or by a `·` separator (`Procedencia · Basis: ...`). A Basis names self when it carries `self`, `own reasoning`, `razonamiento propio`, `eigene Überlegung` or `eigene Ueberlegung` as a standalone word (case-insensitive), or when one of its items (split on `,` `;` `+` `&` and/y/und) is nothing but a self source (`myself`, `self-evident`, `my own reasoning`, `reasoning`). `self` inside a longer token is not a self source: `scripts/selftest.py` and `self-review of scripts/x.py` are SOURCED, `myself` and `self-evident` alone are SELF. A SOURCED line written after a SELF one (in a code block or not) does not lift it: over-reading costs two more reviewers, never a weaker check. Otherwise the reply is SOURCED. Distinct means distinct agent ids: one reviewer recorded three times is one reviewer. `receipt_ledger.panel_receipts_for` holds the per-receipt validation and returns every validated receipt, deciding first (a PASS whose anchor check raises counts as not standing); `panel_latest_for` returns its first entry, so `panel_pass_for` and the send gate are unchanged. The stderr names the source class and the count ("it has 1 of 3"). The status-line exemption for a pending reviewer is the same for both classes.

**A receipt is not spent.** It is bound to one exact text and one operator turn. A receipt from an earlier turn never covers this one, and a NEEDS-WORK newer than the PASS revokes it (the ledger's own rule). Repeating the identical text in the same turn is the same reply.

**Status line while a subagent runs.** The gate scans the session transcript forward from the newest compact summary. A subagent is running when an `Agent` or `Task` call was acknowledged as launched in the background (`toolUseResult.isAsync: true`, keyed by its `agentId`) or an agent was resumed by `SendMessage` (`toolUseResult.success: true`), and no hand-back from it (a user or `queued_command` attachment entry whose origin is `{"kind": "peer", "from": <agentId>}`), no task notification naming the call (`<tool-use-id>`) and no `TaskStop` came after that launch. A launch older than 120 minutes (`PENDING_MAX_MINUTES`, measured against the newest transcript entry) is not counted: a killed agent leaves no hand-back. Any subagent counts: a panel reviewer, a QA seat, a builder, one resumed by `SendMessage` for a second round. The status line carries no claim: `status_claim` rejects an outcome word (EN `passed`, `merged`, `done`, `sent`, `found`; ES `listo`, `hecha`, `mandé`, `encontró`; DE `fertig`, `erledigt`, `gefunden`, and their kin) anywhere, and a digit outside a provenance line. The newest pending id is appended to `~/.claude/.cache/receipts/reply-pending.jsonl` as an audit row; a ledger that cannot be written is an error.

**Fail-closed.** An unparseable payload, a payload without `last_assistant_message`, no operator prompt, an unreadable transcript, an import error, a missing helper, a receipt ledger that is not a readable file, an unreadable or unwritable `reply-pending.jsonl`, or an exception from the ledger exits 2 with the error named. A missing receipts directory is no receipt, not an error. The way out is the operator's: `panel-skip` in his own prompt for one turn, `OCTO_REPLY_PANEL=off` in the launching shell for the session. A turn opened by a compact summary carries no operator words, so `panel-skip` cannot apply there; such a turn clears with a panel receipt newer than the summary, or with the off switch. The main loop cannot set the second one: a Bash export does not reach hook processes. The harness sets `CLAUDE_CODE_CHILD_SESSION=1` in hook commands; the gate ignores it.

## Proof

`python3 scripts/g__stop__reply-panel.py --selftest registry/fixtures/FLOW.panel-before-reply`. Each `violation_*.json` must exit exactly 2, each `benign_*.json` exactly 0, every case in its own sandbox HOME. A case's optional `_fixture` key (stripped before the gate sees the payload) seeds receipts through `panel_fixture_seed.seed_reply_receipt`, pre-records spent ids, breaks the ledger, sets env, and asserts on stderr and on the spent ledger. The run scrubs `OCTO_REPLY_PANEL`, sets `CLAUDE_CODE_CHILD_SESSION=1`, and pins the clock to the newest transcript entry under `CLAUDE_SESSION_ID=__selftest__`, so the 120-minute window never ages the fixtures out. Two unit checks run first: the digest (AC-01) and a copy of the gate whose send gate lacks `_origin` (AC-17), which must exit 2 naming it. Every blocked case must also be journaled under `FLOW.panel-before-reply`.

`brain_doctor` covers the rule through its generic checks: `registry-wiring` (the gate in `hooks.json` at Stop), `registry-anchors` (the "Reply panel" anchor in CLAUDE.md) and `gate-liveness` (the selftest). `reply-panel-arm-env` warns when an arm settings file sets the off switch (R-10).
